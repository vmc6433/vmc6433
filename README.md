### ♻️ AI-Powered Smart Waste Segregation System

An AI-based system that classifies waste into four categories and automates segregation using computer vision and hardware control.

- **Model:** EfficientNet-B0
- **Framework:** PyTorch
- **Dataset:** 15,110 images across four categories
- **Test accuracy:** 97.44%
- **Macro F1-score:** 96.82%
- **Test samples:** 2,266 images, with 2,208 correct predictions
- **Hardware:** Raspberry Pi 5, Arduino UNO, servo motor, and NEMA 17 stepper motor
- **Classes:** Plastic, E-waste, Organic, and Recyclable
